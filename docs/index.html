Senior Software Engineer | Systems Engineer & MIS Specialist | Full-Stack, Software Architecture, Stripe & Data Analytics (GA4/GTM)

Ingeniero de Sistemas y Especialista en Gestión de Sistemas de Información con más de 7 años de experiencia diseñando, modernizando y escalando arquitecturas de software de alto rendimiento, plataformas e-commerce y soluciones empresariales. Mi enfoque combina el desarrollo Full-Stack sólido (PHP 8.x, JavaScript, Java/Spring MVC) con analítica de datos avanzada (GA4, GTM Data Layers) e infraestructura en la nube (AWS, GitHub Actions, Docker). Tengo una trayectoria comprobada transformando motores de pago y suscripción, optimizando embudos de conversión (CRO) y garantizando la alta disponibilidad del software mediante soporte técnico de nivel 3 (L3) en entornos internacionales.
